# Cyberpunk 2077 — Build Tracker

Estrutura estática com páginas separadas.

## Arquivos

```txt
cyberpunk-build-tracker/
├─ index.html
├─ builds/
│  └─ netrunner.html
└─ assets/
   ├─ styles.css
   ├─ netrunner-data.js
   └─ build-tracker.js
```

## Como usar

Abra `index.html` no navegador.

A página da build Netrunner está em `builds/netrunner.html`.

O progresso do checklist é salvo no navegador via `localStorage`.
